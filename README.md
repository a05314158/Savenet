# Проект "Savenet": Умный Ассистент для Цифровой Гигиены

## 📖 Описание Проекта

Savenet — это расширение для браузера и/или десктопное приложение, призванное помочь пользователям восстановить контроль над своим цифровым временем, уменьшить отвлекающие факторы, повысить продуктивность и улучшить общее цифровое благополучие. В эпоху постоянного информационного потока и уведомлений, Savenet станет вашим надежным партнером в достижении осознанного взаимодействия с цифровым миром, используя передовые технологии искусственного интеллекта для персонализации рекомендаций и прогнозирования поведения.

## ✨ Ключевые Особенности

*   **Интеллектуальная Блокировка Отвлекающих Сайтов/Приложений:** Пользователь может настроить списки блокировки для определенных сайтов или категорий сайтов (например, социальные сети, развлечения) и приложений. Блокировка может быть активирована по расписанию, по таймеру или вручную.
*   **Подробная Статистика Использования:** Визуализированные отчеты о времени, проведенном на различных сайтах и в приложениях, помогут пользователю осознать свои цифровые привычки.
*   **Напоминания о "Микро-Перерывах":** Интегрированные подсказки для коротких, восстанавливающих перерывов, включающие в себя:
    *   Упражнения для глаз и шеи.
    *   Короткие дыхательные практики или медитации.
    *   Предложения пройтись или выпить воды.
*   **"Режим Фокуса":** Активация данного режима временно блокирует все уведомления и включает строгую блокировку отвлекающих ресурсов, позволяя полностью сосредоточиться на задаче.
*   **Генерация Кратких Саммари (для продвинутой версии):** Интеграция с NLP для создания кратких изложений длинных статей, новостей или даже видео (через транскрипцию), позволяющая получать основную информацию, экономя время.
*   **AI-Аналитика и Персонализированные Рекомендации:**
    *   **Анализ Статистики:** Использование нейронных сетей для выявления паттернов в использовании цифровых ресурсов (например, когда пользователь наиболее продуктивен, когда чаще отвлекается).
    *   **Прогнозирование Поведения:** ИИ-модель будет прогнозировать время, которое пользователь, вероятно, проведет на отвлекающих сайтах/приложениях на следующей неделе или в определенные периоды, основываясь на предыдущих данных.
    *   **Интерактивный AI-Коуч:** Пользователь может задавать вопросы (например, "Как мне увеличить продуктивность?" или "Почему я так много времени провожу в соцсетях?"). ИИ будет анализировать его личную статистику и давать персонализированные советы и стратегии для улучшения цифровой гигиены и продуктивности.

## 💡 Концепция и Принципы Работы

Savenet строится на принципах **осознанного потребления**, **активного управления** своим цифровым временем и **интеллектуальной адаптации**. Мы не просто блокируем, но и обучаем, предоставляем инструменты для самоанализа и поощряем здоровые цифровые привычки, используя мощь искусственного интеллекта для создания по-настоящему персонализированного опыта.

1.  **Сбор Данных (Локально):** Расширение/приложение анонимно собирает детальные данные об использовании браузера/приложений (посещенные сайты, время на них, активность, переключения между задачами). Эти данные хранятся *локально* на устройстве пользователя, обеспечивая полную конфиденциальность.
2.  **Анализ и Визуализация:** Собранные данные анализируются и представляются пользователю в виде понятных графиков и отчетов, показывая, где он проводит свое время.
3.  **ИИ-Обработка и Прогнозирование:** Локальная или облачная нейросеть обрабатывает исторические данные, выявляет глубокие паттерны, дает рекомендации и строит прогнозы.
4.  **Настраиваемые Правила:** Пользователь задает свои правила, при этом ИИ может предлагать оптимальные настройки на основе анализа его поведения.
5.  **Активное Взаимодействие:** Savenet не просто работает в фоновом режиме, но и активно взаимодействует с пользователем, предлагая перерывы, сообщая о достижении лимитов или предлагая "Режим Фокуса" и предоставляя персонализированные рекомендации от AI-коуча.
6.  **Конфиденциальность:** Основной упор делается на то, что все данные об использовании остаются на устройстве пользователя. Облачное хранение может быть опцией только для синхронизации настроек между устройствами и для обучения общих моделей ИИ (с агрегированными, анонимными данными) и только с явного согласия пользователя.

## 🎯 Целевая Аудитория

*   **Студенты:** Нуждающиеся в концентрации для учебы, но постоянно отвлекающиеся на социальные сети и YouTube.
*   **Фрилансеры и Удаленные Работники:** Стремящиеся к самодисциплине и эффективному управлению рабочим временем в домашних условиях.
*   **Офисные Работники:** Желающие минимизировать отвлечения во время выполнения задач.
*   **Люди, Заботящиеся о Своем Цифровом Благополучии:** Те, кто ощущает зависимость от гаджетов, испытывает "цифровую усталость" и хочет сократить экранное время.
*   **Проактивные Пользователи:** Те, кто ищет инструменты для саморазвития и оптимизации своего времени с помощью передовых технологий.

## 🛠️ Стек Технологий и Идея Реализации

### Общая Архитектура

Savenet будет иметь модульную архитектуру, позволяющую комбинировать расширение для браузера и десктопное приложение для максимальной эффективности.

### Вариант 1: Расширение для Браузера (MVP)

*   **Фронтенд (UI/UX):** HTML5/CSS3, JavaScript (Vanilla JS/React/Vue).
*   **Бэкенд (Логика Расширения):** JavaScript (Web APIs - `chrome.*`, `browser.*`).
*   **Хранение Данных:** `chrome.storage.local` / `browser.storage.local`.

### Вариант 2: Десктопное Приложение (Для более полного контроля и функций)

*   **Фронтенд (UI/UX):** Electron (JavaScript, HTML, CSS, Node.js) с React/Vue/Angular.
*   **Бэкенд (Логика Приложения):** Node.js с нативными модулями (C++/Python) для взаимодействия с ОС.
*   **Хранение Данных:** SQLite / JSON-файлы.

### Дополнительные/Продвинутые Функции (с AI)

*   **Модуль AI-Аналитики и Прогнозирования:**
    *   **Язык:** **Python** (предпочтительно из-за богатой экосистемы для ML).
    *   **Библиотеки:**
        *   **Pandas/NumPy:** Для обработки и анализа данных.
        *   **Scikit-learn:** Для классических алгоритмов машинного обучения (линейная регрессия, временные ряды, кластеризация для выявления паттернов).
        *   **TensorFlow/PyTorch:** Для построения и обучения более сложных нейронных сетей (например, LSTM для прогнозирования временных рядов использования).
    *   **Интеграция:**
        *   **Десктопное приложение (Electron):** Python-модуль может быть запущен как отдельный процесс или интегрирован через `python-shell` или HTTP-интерфейс (`Flask`/`FastAPI` микросервис), работающий локально.
        *   **Расширение для браузера:** Интеграция сложнее. Возможно обращение к локально запущенному HTTP-сервису (как в Electron) или использование внешних API.
*   **Генерация Саммари (NLP) & AI-Коуч (NLP):**
    *   **Python:** С библиотеками `NLTK`, `SpaCy`, `transformers` (Hugging Face) для обработки естественного языка и генерации текста.
    *   **API:**
        *   **Локально:** Использование небольших моделей `transformers` или `SpaCy` для локального запуска (требует определенных вычислительных ресурсов).
        *   **Внешние AI API:** Интеграция с коммерческими сервисами, такими как OpenAI GPT, Google Gemini, Anthropic Claude. Это самый простой способ получить продвинутые NLP-возможности, но требует ключей API и потенциально отправки данных в облако (с согласия пользователя).
*   **Облачная Синхронизация (Опционально):** Node.js/Python бэкенд (Express/Django/FastAPI), PostgreSQL/MongoDB, OAuth2/JWT.

## 🚀 План Реализации (MVP)

1.  **Инициализация Проекта:** Создание базовой структуры расширения для Chrome (манифест, пустые файлы HTML, CSS, JS).
2.  **Мониторинг Активности:** Реализация отслеживания активной вкладки и URL, а также времени, проведенного на каждом сайте.
3.  **Базовая Блокировка:** Возможность добавлять сайты в список блокировки и активировать ее вручную или по простому таймеру.
4.  **Визуализация Статистики:** Простой дашборд с графиком использования за день/неделю.
5.  **Настройки Пользователя:** Интерфейс для управления списками блокировки и основными параметрами.
6.  **"Режим Фокуса":** Простая кнопка, которая активирует строгую блокировку всех отвлекающих сайтов на определенный период.
